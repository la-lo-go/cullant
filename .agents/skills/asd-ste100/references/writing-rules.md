# ASD-STE100 writing rules

This file summarizes public ASD-STE100 rule categories. It does not reproduce the official
dictionary or certify compliance. Use the official publication when exact approved wording
is required.

## Vocabulary

- Use a common word in one approved meaning and one part of speech.
- Use the same term for the same concept.
- Prefer a short, common word to a formal synonym.
- Add project-specific technical nouns and verbs to a glossary.

## Verbs and voice

- Use the infinitive, imperative, simple present, simple past, or simple future.
- Do not use perfect or other compound tenses.
- Use an `-ing` form only when it is a technical noun.
- Use active voice for instructions.
- Use passive voice in a description only when the actor is unknown or irrelevant.

## Sentences

- Put one instruction in each sentence.
- Keep an instruction at 20 words or fewer when precision permits.
- Keep a description at 25 words or fewer when precision permits.
- Keep the subject, verb, and article explicit.
- Limit noun clusters to three words.
- State a safety condition before the action that depends on it.

## Structure

- Keep one topic in each paragraph.
- Keep a paragraph at six sentences or fewer when precision permits.
- Use vertical lists for sequences, multiple conditions, and complex sets.

## Precision rule

Precision has priority over length. Do not remove a condition, exception, unit, number,
identifier, or scope qualifier to meet a sentence limit. Explain the conflict and keep the
required information.

## Authoritative source

The official standard and current issue information are available from
https://www.asd-ste100.org/.
