# Supporting Cullant

Cullant is free and open source under the GPL-3.0-or-later. There are no ads, no
account, no subscription and no paid tier. It never sends your photos, or
anything about them, anywhere: there is no telemetry and no analytics in the app
at all.

That also means nothing funds it. If Cullant saves you time, here is how to help.

## Ways that cost nothing

These are worth more than they sound.

- **Star the repository.** It is the cheapest way to help other photographers
  find it.
- **Report bugs and ideas.** A precise report with the camera model, the file
  and what you expected saves hours of guessing.
- **Send RAW files from your cameras.** This is the single most useful thing
  right now. Every camera body writes RAW slightly differently, and the decoding
  path cannot be tested properly against bodies nobody has files from. Open an
  issue with the `raw-samples` label and a couple of frames straight off the
  card.
- **Tell another photographer.** Word of mouth is the only distribution this has.

## Ways with money

**None of these are live yet.** The accounts are not open, so the buttons inside
the app link to this page rather than pretending to work. This section is the
one place that says what is actually available, and it is updated as each opens.

| How | Status |

If you want to contribute money before any of these exist, open an issue and say
so. Knowing there is real interest is itself a reason to set them up.

## Contributing code

Pull requests are welcome. The project guide in `CLAUDE.md` covers the stack, the
layout and the conventions, including the checks a change has to pass before it
is committed.
